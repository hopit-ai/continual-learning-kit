# kit/

What a GPU partner receives. Nothing here depends on Modal, and nothing here is confidential: it launches public code and summarises results.

| File | What it is |
|---|---|
| `runner.py` | Runs a campaign file row by row on any machine, **with the pilot gate**: a row marked `pilot: true` is judged against bars written in advance, and every later row is refused unless the pilot's latest verdict is PASS. Writes `start.json` before launching and `verdict.json` after; never overwrites; a retry is a new attempt. `plan` prints what would run and executes nothing. |
| `campaigns/toy.yaml`, `toy/fake_train.py` | The smallest campaign that exercises the gate; runs on a laptop in a second. |
| `campaigns/k0-sdpo-toolalpaca.yaml` | Package K0 (batch 0) as a campaign: the smoke is the pilot, the five real runs need it. |
| `run_sdpo_toolalpaca.sh` | Launches the pinned SDPO reference on ToolAlpaca; receipt 201 proves its arguments equal our run 3's record. |
| `make_report.py` | Turns run directories into `report.md` and `report.json`, the two files a partner sends back. |
| `score_forgetting.py` | Scores a saved model on 300 fixed questions (maths, knowledge, instruction following), one greedy answer each, with the same prompts, decoding and scoring code as our own harness. `generate` needs vLLM and one GPU; `score` and `compare` need nothing. **`compare` only judges two results scored on the same machine** and answers NOT_COMPARABLE otherwise, because cross-machine noise is as large as the 3-point floor (receipt 204). |
| `scorers.py`, `panels/general-v1.jsonl` | Generated by `scripts/make_kit_forgetting_assets.py` from the frozen originals; never hand-edited. |
| `stage_local.py` | Puts inputs on the GPU machine's local disk before the GPU does any work. `pack` (CPU, once): many small files into one deterministic archive with per-file hashes, 16 concurrent readers. `unpack` (GPU start): copy, extract, verify, leave a marker so later runs reuse it. `mirror`: the same for a few large files such as model weights. Use it as a row's `prepare` step and first command. |
| `beds/finqa.py` | FinQA as a bed: prompts, a scoring rule that accepts percent-or-decimal and analyst-style rounding, a reward function in the SDPO reference's shape whose feedback never carries the answer, label-problem flags, and a `prepare` step that writes trainer files on CPU. |
| `README-partner.md` | The instructions for package K0, from clone to report. |
| `README-k2.md`, `campaigns/k2-recovery-test.yaml`, `repair/` | Package K2, the recovery test: is a damaged model's lost ability still inside it? `repair/prompts.py` (1,000 everyday prompts with no maths, exam questions or formatting rules), `make_targets.py` (the original model answers them), `train_lora.py` (a 300-step adapter, saved at 50/100/200/300), `merge.py` (tokenizer copied byte for byte), `drift.py` (how far the weights moved), `damage_check.py`, `report.py`. The campaign is generated by `scripts/make_k2_campaign.py`; its first 13 rows are a pilot on a 0.6B model damaged on purpose, and every 8B row is refused until it passes. |
| `README-k1a.md`, `campaigns/k1a-forgetting-of-k0.yaml` | Package K1a: forgetting scores for the five K0 models, 25 minutes on one GPU, with a pilot that scores the untrained model twice and refuses to continue unless the two agree. |

Rule: **no row runs big unless the same experiment ran small first and passed.** See `docs/plan-open-sota-20260919.md` section 1.
