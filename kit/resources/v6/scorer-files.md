## Owner sign-off still required for GPU-only computations

- `eval_bed.py`, `score_forgetting.py`, `m2_format.py`, `sp_score.py`: actual vLLM outputs, prompt likelihoods and GPU kernel equality under the selected lane profile.
- `s_drift.py`, `s_probe.py`: HF NLL likelihoods on actual weights; the CPU replay establishes arithmetic and split/reducer parity on recorded inputs.
- `s_generate.py`, `next_pools.py`, `v4_teacher.py`: actual generated tokens and verification on the registered full pools; CPU acceptance and prompt logic are replayed.
- `s_probe_train.py`: distributed FSDP update and native-to-export tensor equality. CPU response-CE parity alone does not qualify distributed training.
- `sp_prepare.py`: the historical frozen construction remains immutable; its full authored-panel construction and provenance are still governed by the existing frozen records and tests.
- HF references and PD FP32 scoring: K=3 is unqualified and disabled. This infra controller uses K=1; any K=2 PD execution must come from the separately reviewed per-cell implementation.

These are review items for the final send. They are not permission requests or
claims that an allocation sustains 70% activity. No GPU or paid job was launched.

## Pin inventory and historical generations

Only current checker inputs are sources: S registration code, SP FROZEN code,
3c annex implementation, C freeze files, effective format-validity plus its
near-tie replacements, and current SHA256SUMS maps. Each generated row records
its exact `pin_sources`. A historical generation remains eligible only if one
of these current inputs still explicitly pins it. The old runtime-update map
continues to permit its original exact transition; its original/v2 fields are
allowlist pairs, not independent demands to approve both versions anew.
Embedded implementation snapshots in smoke results, pool manifests, ARC attempt
receipts, legacy data maps and construction reviews prove historical provenance;
they do not demand that the current executable match those historical bytes.
The generator no longer invents a transition for the base commit hash itself.
